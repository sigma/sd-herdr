The Rex session this button speaks for. The choice is stored by id, so renaming the session in Rex keeps the tile. Until one is set, or if it no longer exists, the tile stays grey.

The herdr session this button speaks for. One tile speaks for exactly one session — add a second button for a second session. Two buttons on the same session share a single poll.

Bundle id of the terminal hosting this session, used only when the plugin cannot work out which application to raise — inside tmux or zellij, or over SSH. The key flashes on any press that has to fall back to it, so a wrong value here announces itself rather than quietly raising the wrong window.
